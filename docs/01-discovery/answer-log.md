## 현재 토론

사용자는 스크립트 언어를 지금 비교·결정하고, 충분히 예측 가능한 다른 선택도 미루지 않기를 원한다. 조정자는 TypeScript strict를 권고했으나 사용자는 “그 장점에도 왜 TS 게임이 잘 보이지 않는가”를 질문했다. 따라서 언어는 미선정이며 실제 게임·스크립트 통합 사례와 엔진 코어/게임플레이의 차이를 추가 조사한다. 권고를 사용자 선택으로 기록하지 않는다.

실시간 답변이 도착하면 해당 질문의 답과 영향받는 문서를 갱신한다. 답변이 없다는 이유로 옵션의 첫 항목을 채택하지 않는다.

## 변경·충돌 기록

- 원안에서 UI·서버가 마지막 단계였지만 A-004·A-007에 따라 초기 공통 설계로 이동.
- 처음 설명했던 별도 검증 프로젝트 구상은 A-012로 현재 범위에서 제외. 현재 산출물은 엔진의 구조·품질·검증 명세이다.
- “전체 플랫폼”은 사용자 목표이며 현재 지원 인증이 아니다. 플랫폼별 달성 증거는 이후 별도로 기록.

## 다음 대화 운영

한 번에 4~6개 정도의 서로 관련된 질문을 제시한다. 답변을 반영한 뒤 다음 묶음으로 이동한다. 질문은 단순 취향 수집이 아니라 어떤 소유권·시뮬레이션·렌더·배포 선택이 달라지는지 설명한다. 전체 질문 풀은 [질문지](questionnaire.md)에 둔다.

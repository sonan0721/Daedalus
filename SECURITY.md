# Security policy

Please do not publish details of an unpatched vulnerability in a public issue or pull request.

If GitHub private vulnerability reporting is enabled for this repository, use the [private report form](https://github.com/sonan0721/Daedalus/security/advisories/new). Its availability depends on the repository settings; this document does not claim that it is enabled. If the form is unavailable, contact the maintainer [@sonan0721](https://github.com/sonan0721) through GitHub and ask for a private reporting channel without posting sensitive details publicly.

Daedalus is currently in planning and design, so there is no released engine or support window to report here. As implementation and releases begin, this policy should be updated with supported versions and response expectations.

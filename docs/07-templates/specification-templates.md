# 조사·명세·goal·ADR 템플릿

상태: 후속 문서 작성용. 빈 템플릿은 조사 완료 근거가 아님 · 2026-10-15

## 조사 노트

```text
제목 / ID / 날짜 / 상태
질문: 이 조사로 어떤 결정을 할 것인가?
확정 요구와 미결: REQ·답변 ID
1차 자료: URL·조회일·version/commit·실제로 읽은 범위
확인 사실: 자료가 직접 뒷받침하는 내용
비교: 대안·비용·반례·플랫폼 제약
다이달로스 적용안: 소유 모듈·입출력·교체 경계
검증할 가설: 문서로 확인 불가능한 것·최소 실험
결론: 채택/기각/미결·이유·ADR 연결
사용자 설명: 이 파일을 만든 이유와 핵심 요약
```

## Goal 카드

```text
ID / 상태 / 담당 역할
목적: 관찰 가능한 최종 상태
연결 요구·ADR·이슈
선행: 필요한 결정·문서·환경
산출물: 정확한 파일·API·artifact
제외 범위: 작업이 무한히 넓어지지 않는 경계
종료 조건: 입력·정확성·성능·플랫폼·증거
검증 명령: 실제 존재하거나 미래 계획인지 표시
미결·위험·중단 조건
결과: commit·실행 환경·원시 근거·제약
```

## ADR 카드

```text

대안·선택 비용
결정: 구체적인 계약과 제외한 가정

```

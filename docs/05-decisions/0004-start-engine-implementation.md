# ADR-0004: 엔진 구현 착수와 단계별 검증

날짜: 2026-10-15 · 상태: 채택 · 근거: 사용자의 명시적 엔진 구축 착수 요청

## 맥락

설계 문서와 언어·런타임 방향을 검토한 사용자가 Luna xhigh에게 코딩을 맡겨 엔진을 구축하도록 요청했다. 이전의 구현 미착수 제약은 이 요청으로 변경된다. 물리·오디오·제작·내비·UI 등 일부 상세 설계와 성능 계약은 여전히 미완료다.

## 결정

1. 코어 workspace·데이터 소유권·스케줄·명령·테스트 기반부터 실제 구현을 시작한다.
2. 세부 설계가 필요한 모듈은 관련 Markdown 계약을 먼저 보완하고 구현·검증한다. 전체 설계 게이트를 이미 통과했다고 선언하지 않는다.
3. 프로젝트 소스·테스트·CI·스크립트·셰이더·빌드 설정은 Luna xhigh가 작성한다. 조정자는 명세·작업 정의·리뷰·실행 검증·통합을 담당한다.
4. shared worktree의 작업은 파일 소유권을 분리한다. API 선행 관계를 공유하고 통합 후 전체 검사를 수행한다.
5. 샘플 게임 대신 검증 목적·입력·기대 결과가 있는 최소 엔진 fixture를 사용한다.
6. 실제 실행 명령·결과·환경·artifact와 미완료 항목을 체크리스트·TESTING에 기록한다. 파일 생성·trait 정의·mock 성공 응답만으로 기능을 완료 처리하지 않는다.
7. 사용자 동의에 따라 .NET 10은 사용자가 설치했다. 로컬 확인: SDK 10.0.402, CoreCLR 10.0.13, osx-arm64. Rust는 1.94.0이다. 프로젝트 pin은 Luna가 작성하며 필요 SDK를 자동으로 시스템에 설치하지 않는다.

## 결과와 남은 게이트

컴파일·CPU 정확성·GPU 실행·C# host·창/웹·서버·장시간 품질 검증을 구분한다. 실제 검증하지 않은 플랫폼은 미검증으로 남긴다. 144fps와 참조 게임의 완성도는 승인된 부하·화질·행동 기준이 있어야 검증할 수 있다.

공통 데이터·bounded 통신·thread ownership과 Rust/C# 역할은 ADR-0002·0003을 유지한다. 실행 중 전체 native DLL 교체나 두 번째 스크립트 언어 지원을 이 착수 결정으로 추가하지 않는다.

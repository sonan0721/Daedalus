# ADR-0001: 독립 엔진과 저장소 운영 경계

상태: 채택 · 결정 근거: 사용자 대화 A-001~018 · 2026-10-15

## 맥락

처음 제안은 2D·3D 게임 기능을 구현하는 6단계 계획이었다. 사용자는 단순 시연이 아닌 고품질 게임 제작 역량을 가진 독립 엔진을 원하며, 지금은 엔진 설계를 우선하고 샘플 프로젝트를 시작하지 않도록 명확히 했다.

## 결정

- 이름은 Daedalus, 한국어 다이달로스.
- 검증된 ECS·GPU·물리 등 부품을 활용하는 독립 엔진. Bevy 전체 포크를 기본 전제로 삼지 않음.
- 이 저장소는 엔진·문서·도구·엔진 테스트 전용. 샘플 게임·모작 프로젝트를 지금 추가하지 않음.
- macOS·웹 우선, Windows·Linux·모바일·후속 콘솔을 위한 경계 설계.
- 픽셀/HD 2D, 복셀/일반 3D 오픈월드, 약 30명 전용 서버를 설계 범위에 포함.
- 코드·CLI·MCP와 사람이 볼 실행 창을 제공하는 방향.
- 계획·조사·아키텍처를 MD로 먼저 정리. 구현 착수는 후속 단계.
- `sonan0721/Daedalus` 공개, 원본 엔진·도구·문서 MIT OR Apache-2.0.
- 프로젝트 소유 코딩은 Luna xhigh, 조정자는 조사·설계·리뷰·통합. 주기적이고 일관된 커밋.
- 품질 우선. 임의 기한 때문에 장기 요구를 삭제하지 않음.

## 결과와 재검토

문서·테스트·기여 체계도 엔진의 일부로 관리한다. 외부 에셋·SDK는 원래 조건을 유지한다. 추후 별도 샘플 프로젝트가 필요해져도 현재 저장소 경계를 자동으로 확대하지 않는다. 변경은 새로운 사용자 결정과 ADR로 추적한다.

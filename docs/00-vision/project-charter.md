# 다이달로스 프로젝트 헌장

상태: 사용자 확정 방향 + 세부 범위 미결 · 갱신: 2026-10-15

## 존재 이유

다이달로스(Daedalus)는 1인 개발자가 AI와 함께 높은 품질의 2D·3D 게임을 제작할 수 있도록 설계하는 독립 게임 엔진이다. 코드, CLI, MCP, DCC 에셋 파이프라인과 사람이 직접 보는 실행 창을 주요 접점으로 삼는다.

단순히 복셀을 표시하거나 타일을 움직이는 기술 시연을 완성으로 보지 않는다. 조작, UI, 액션, 애니메이션, 오디오, 로딩, 네트워크, 저장, 배포와 디버깅을 포함하는 엔진 역량을 목표로 한다. 기능별 지원 수준은 [범위표](feature-quality-matrix.md)로 정의한다.

추가 확정: 2D는 픽셀·고해상도 표현 모두, 3D는 복셀·일반 오픈월드 모두 포함한다. 웹 배포·설치형 배포·오픈소스 엔진 버전 관리가 필요하다. 웹·설치형은 기능·저장 형식·script API를 유지하고 기기별 화질 조정은 허용한다. 웹은 쉽게 내보낼 수 있는 HTML/Wasm 배포를 뜻하며 호스팅 서비스 개발 요청이 아니다.

스크립트는 공식 엔진 API부터 지원하고 외부 패키지·모드는 후속 검토한다. C#의 구조화된 언어 체계와 게임 개발자 친숙성도 중요한 기준이다. C#·TS·Luau를 현재 토론 중이며 TS로 확정한 상태는 아니다.

기준 개발 장비는 사용자의 현재 MacBook Pro: Apple M3 Pro, CPU 12코어(성능 6·효율 6), GPU 18코어, 통합 메모리 18GB, 내장 화면 3024×1964이다. 2026-10-15 로컬 시스템 정보로 확인했다. 화면 해상도가 벤치마크의 내부 렌더 해상도로 확정된 것은 아니다.

## 품질을 해석하는 기준

언급한 게임은 선호와 목표를 전달하는 참조이다. 게임 전체를 복제하거나 엔진 하나가 같은 완성도에 자동으로 도달한다고 해석하지 않는다. 각 참조를 재질, 그림자, 색·노출, 캐릭터, VFX, UI, 카메라, 조작 반응 등의 관찰 가능한 항목으로 분해한다. 어떤 항목을 어떤 플랫폼에서 충족해야 하는지 사용자와 합의한다.

스타일라이즈드와 사실적 표현은 서로 다른 재질·라이팅·포스트프로세싱 설정을 요구할 수 있다. 공통 엔진이 이를 확장 가능한 방식으로 수용하는 것이 목표이며, R01에서 단일 렌더 기법을 정답으로 고정하지 않는다.

## 현재 작업의 경계

지금 만드는 것은 엔진 조사·설계·기여 체계다. 엔진 런타임, 샘플 게임, 대규모 에셋 다운로드, 콘솔 SDK 연동을 시작하지 않는다. 문서 검증과 GitHub 기여 자동화는 이번에 구축하는 저장소 기반 시설이다.

향후 기능 검증에는 작은 엔진 테스트 장면·결정적 입력 데이터가 필요하다. 이는 전용 테스트 목적과 크기·라이선스가 명시되어야 하며 샘플 게임으로 확대하지 않는다.

## 설계 완료의 의미

모든 미래 문제를 미리 해결했다고 선언하지 않는다. 핵심 결정에 근거·비교·실험 계획이 있고, 소유권·실패·플랫폼·성능 계약을 리뷰할 수 있으며, 미결 사항의 영향과 처리 시점을 아는 상태를 설계 게이트의 목표로 한다. 코드로만 확인할 수 있는 가설은 이후 최소 기술 실험으로 검증하고 명세를 갱신한다.

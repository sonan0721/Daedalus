## 이번 범위

사용자와 언어·런타임·모드 우선순위·Unity Lua 경험·Rust 게임플레이 창구를 토론했다. 최종 방향은 C# 14/.NET 10 LTS/CoreCLR 주 SDK, Rust 코어·빌드형 게임플레이, C++ FFI 부품, 두 종류의 오토파일럿이다. PC 모드를 우선하고 엔진의 장기 웹/추가 플랫폼 목표는 유지한다.

## 조사 한계와 구현 경계

공식 C#/.NET, Unity 6.3 backend·Test Framework, xLua, Rust FFI/ABI, CXX와 Steam Workshop 문서를 확인했다. 사용자의 과거 Unity 프로젝트나 Lua 플러그인 코드는 확인하지 않았다. Lua 도입 원인은 추론이며 xLua 사용을 단정하지 않는다.

엔진·SDK·C# host·native bridge·게임 샘플은 구현하지 않았으며 runtime 설치·통합 벤치마크도 수행하지 않았다. 이번 변경은 Markdown만 포함한다. 모든 후속 코딩은 기존 규칙대로 Luna xhigh에게 위임한다.

## 검증

- 로컬 `python3 scripts/check_docs.py`: 통과.
- 로컬 `python3 -m unittest discover -s scripts -p 'test_*.py'`: 기존 검사기 테스트 8건 통과.
- `git diff --check`: 통과.
- PR·GitHub CI·병합 상태는 이 변경의 Git/PR 이력으로 확인한다.

엔진 기능 인수 시나리오는 향후 계획이며 이번 검증 대상이 아니다. 문서 검사로 실제 host·FFI·hot-reload·오토파일럿 동작을 확인했다고 주장하지 않는다.

## 아직 수치화하지 않은 계약

최소 Mac, 브라우저 목록, 해상도, 품질 단계, 목표 fps, UI 응답 지연, 서버 인원, 활성 셀·청크 수, 시야 거리, 월드 변경률, 다운로드 크기, RAM·VRAM·저장 상한이 필요하다. [질문지](../01-discovery/questionnaire.md)에서 순차적으로 확인한다.

## 변경 규칙

요구를 추가·수정할 때 답변 기록, 영향받는 아키텍처, goal, 검증 기준을 함께 갱신한다. 아직 지원하지 않는 요구를 삭제하여 완료로 보이게 하지 않는다. 필요하면 장기 목표와 해당 릴리스의 인수 범위를 분리하고 사용자의 결정 근거를 남긴다.

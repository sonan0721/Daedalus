## 아직 수치화하지 않은 계약

기준 Mac(M3 Pro·18GB), 목표 144fps 이상, 약 30명 서버는 이미 답변을 확보했다. 최소 지원 기기·브라우저 목록, 내부 해상도·품질 단계·fps 허용 초과율, UI 응답 지연, 30명 부하 분포, 활성 셀·청크 수, 시야 거리, 변경률, 다운로드·메모리·저장 상한은 더 필요하다. [질문지](../01-discovery/questionnaire.md)에서 순차적으로 확인한다.

REQ-019의 공통 API·저장 의미 목표는 유지한다. REQ-022·025의 다운로드형 PC 플러그인·빌드형 native 확장까지 모든 타깃에 동일한 로딩 방식으로 제공한다는 뜻은 아니다. C# 버전·런타임 세부는 ADR의 기술 기준선이다.

## 변경 규칙

요구를 추가·수정할 때 답변 기록, 영향받는 아키텍처, goal, 검증 기준을 함께 갱신한다. 아직 지원하지 않는 요구를 삭제하여 완료로 보이게 하지 않는다. 필요하면 장기 목표와 해당 릴리스의 인수 범위를 분리하고 사용자의 결정 근거를 남긴다.

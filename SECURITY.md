# Security policy

Please do not publish details of an unpatched vulnerability in a public issue or pull request.

GitHub private vulnerability reporting is enabled for this repository. Use the [private report form](https://github.com/sonan0721/Daedalus/security/advisories/new). If the form is unavailable, ask the maintainer [@sonan0721](https://github.com/sonan0721) for a private reporting channel without posting sensitive details publicly.

Daedalus is currently in planning and design, so there is no released engine or support window to report here. As implementation and releases begin, this policy should be updated with supported versions and response expectations.
